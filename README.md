# emse6035-website

Team project tracker for EMSE 6035 (Marketing Analytics for Design Decisions, GWU, Fall 2026): the project itself (product, attributes, research questions, decision log), a schedule computed with the critical path method on every render, a Gantt chart, a requirements-to-activities coverage check, a risk register, week-by-week progress, a dev log, and a context bank of course facts. A Quarto website, data-driven from the CSVs in `data/`, published with GitHub Pages from `docs/`.

To update: edit the CSVs (or a page), run `quarto render` from the repo folder, commit including `docs/`, push. `CLAUDE.md` has the full brief for anyone (or any agent) working in this repo, including how the schedule is computed.

This repo is public. It carries no grades, no contact details and no credentials.
