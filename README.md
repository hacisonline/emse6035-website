# emse6035-website

Team project tracker for EMSE 6035 (Marketing Analytics for Design Decisions, GWU, Fall 2026): activities, critical path, week-by-week progress, a dev log, and a context bank of course facts. A Quarto website, data-driven from three CSVs in `data/`, published with GitHub Pages from `docs/`.

To update: edit the CSVs (or a page), run `quarto render` from the repo folder in Positron, commit including `docs/`, push. `CLAUDE.md` has the full brief for anyone (or any agent) working in this repo.

This repo is public. It carries no grades, no contact details and no credentials.
