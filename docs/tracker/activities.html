Activities

Every task between now and the final presentation, by phase, with the computed dates beside the planned ones

The activity list lives in data/activities.csv. Each row has an id, a phase, an owner, a planned start and due, an optional hard deadline (the official due date), the ids it depends_on, a status (Not started, In progress, Done, Blocked, Dropped) and a pct complete. Everything else on this page, early and late dates, float, the critical flag, is computed by cpm() in R/helpers.R when the site renders. To change anything, edit the CSV, re-render, push.
